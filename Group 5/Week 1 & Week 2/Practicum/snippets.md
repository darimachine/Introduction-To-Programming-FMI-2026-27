## "Теоретични" въпроси

Примерите са за C++17 и ASCII, при успешен вход и изход. Логическите стойности се извеждат като 0 и 1.

**Ще се компилират ли следните примери код? Какво ще изпишат, ако се компилират? Ако не се компилират, каква е причината?**

```c++
#include <iostream>
using namespace std;

int main() {
  int a = 5;
  a+5;
  cout << a;  
}
```
<details>
<summary>Обяснение</summary>

Програмата извежда **5**. Изразът `a + 5` пресмята 10, но не записва резултата в променливата. За да се промени `a`, трябва присвояване, например `a += 5`.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  int a = 5;
  int b = 4;
  int c = 0;
  cout << a / (!c) + b / (!a);
}
```
<details>
<summary>Обяснение</summary>

Кодът се компилира, но при изпълнение се стига до **деление на нула**. Операторът `!` обръща логическата стойност: `!0` е 1, а `!5` е 0. Така изразът става `5 / 1 + 4 / 0`. Това е недефинирано поведение — няма гарантиран резултат или гарантирано изключение.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  int a = 5;
  int b = 0;
  cout << ((b != 0) && (a / b));
}
```
<details>
<summary>Обяснение</summary>

Short Circuiting:
- операторите && и || оценяват аргументите си отляво надясно
- оператор && спира да оценява аргументите си, когато намери един със стойност false (понеже вече изразът винаги ще е false и останалите аргументи не могат да променят това)
- аналогично, оператор || спира да оценява аргументите си, когато намери един със стойност true

b != 0 се оценява с false, затова целият израз ((b != 0) && (a / b)) също се оценява с false, 'a / b' не се оценява изобщо и програмата изписва 0(false)

Без short circuiting-a, изразът 'а / b' също щеше да се оцени, но в него има деление на 0 => програмата щеше да гръмне

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  int a = 5;
  int b = 0;
  cout << (b != 0) && (a / b);
}
```
<details>
<summary>Обяснение</summary>

Кодът се компилира, но **не е защитен от деление на нула**. Поради приоритета на операторите изразът се разбира като `(cout << (b != 0)) && (a / b)`. Лявата част записва 0 и връща потока `cout`. Тук се проверява дали потокът работи успешно, а не дали записаното число е 0. При успешен запис проверката е вярна и се изпълнява `5 / 0`. Следва недефинирано поведение, затова не можем да обещаем конкретен краен изход. Скобите около цялото логическо условие в предишния пример предотвратяват този проблем.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  cout << ((true || (false && true)) && !true);
}
```
<details>
<summary>Обяснение</summary>

Програмата извежда **0**. Частта `true || ...` е вярна още заради първото `true`, затова останалото в тези скоби се пропуска. Накрая получаваме `true && !true`, тоест `true && false`. Резултатът е `false`, който обичайно се извежда като 0.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  cout << (true || false && true && !true);
}
```
<details>
<summary>Обяснение</summary>

Програмата извежда **1**. Операторът `&&` има по-висок приоритет от `||`, така че изразът е `true || (false && true && !true)`. Първото `true` е достатъчно: дясната част се пропуска и резултатът е `true`, който обичайно се извежда като 1.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  int a = 5;
  double b = 5;
  cout << a / 2 << endl << b / 2;
}
```
<details>
<summary>Обяснение</summary>

Програмата извежда **2**, а на следващия ред — **2.5**. При `a / 2` и двете числа са цели, затова делението отрязва дробната част. При `b / 2` променливата `b` е `double`, затова резултатът може да съдържа дробна част.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  double a = 4.9, b = 5.5;
  int sum = a + b;
  int bToInt = b;
  int sum2 = a + bToInt;
  cout << sum << endl << sum2;
}
```
<details>
<summary>Обяснение</summary>

Програмата извежда **10**, а на следващия ред — **9**. В първия случай първо се събират 4.9 и 5.5, а после резултатът 10.4 се записва в `int` и дробната му част се отрязва. Във втория случай 5.5 предварително става 5. Така сумата е 9.9, която при запис в `int` става 9. Преобразуването към `int` отрязва дробната част, без да закръгля до най-близкото цяло число.

</details>
<br>

```c++
#include <iostream>
using namespace std;

int main() {
  double d = 4.5;
  cout << (d % 2);

  short s = d;
  cout << (s % 2);
}
```
<details>
<summary>Обяснение</summary>

Програмата **не се компилира**, защото `%` работи с цели числа, а `d` е `double`. Присвояването `short s = d` само по себе си е допустимо и би превърнало 4.5 в 4. Тогава `s % 2` би било 0, но това не поправя грешката в първия израз — целият пример трябва да се компилира, преди да може да се изпълни.

</details>
<br>

```c++

#include <iostream>
using namespace std;

int main() {
  int num = 2;
  num *= num += 3;
  cout << num;
}
```
<details>
<summary>Обяснение</summary>

При **C++17** програмата извежда **25**. Изразът се групира като `num *= (num += 3)`. Първо вътрешното `+=` променя `num` от 2 на 5. После външното `*=` използва вече обновената стойност и пресмята `5 * 5`. Този пример показва защо няколко промени на една променлива в общ израз се четат трудно; по-ясно е да бъдат написани отделно.

</details>

## ASCII примери

За долните примери погледнете ASCII таблицата, ако нещо не ви е ясно.
<br><br>

1. Конвертиране на буква от латинската азбука от главна към малка и наобратно:

```c++
#include <iostream>

using std::cout;
using std::endl;

int main() {
  char letterUpper = 'A';
  char toLower = letterUpper + ('a' - 'A');

  char letterLower = 'b';
  char toUpper = letterLower - ('a' - 'A');
    
  // also true
  // char toUpper = letterLower + ('A' - 'a');

  cout << "Original in upper: " << letterUpper << endl;
  cout << "To lower: " << toLower << endl;
  cout << "Original in lower: " << letterLower << endl;
  cout << "To upper: " << toUpper << endl;
}
```

<details>
<summary>Обяснение</summary>

В ASCII между съответните главна и малка латинска буква има разлика **32**. Добавянето на тази разлика превръща `A` в `a`, а изваждането ѝ превръща `b` в `B`. Затова изходът показва последователно **A, a, b, B**, всяка буква със съответния надпис. Формулата е подходяща за латинските букви в ASCII.

</details>

```
Изход:

Original in upper: A
To lower: a
Original in lower: b
To upper: B
```

2. Конвертиране на числов символ към същата числова стойност:

```c++
#include <iostream>

using std::cout;
using std::endl;

int main() {
  char digitChar = '6';
  int digitASCIIcode = digitChar;
  cout << "Digit char: " << digitChar << ", Digit ASCII code: " << digitASCIIcode << endl;

  int digit = digitChar - '0';
  cout << "Digit: " << digit << endl;
}
```

<details>
<summary>Обяснение</summary>

Символът **'6'** и числото **6** са различни неща. В ASCII символът има код **54**, затова присвояването му на `int` дава 54. За да получим числовата стойност на цифрата, изваждаме `'0'`, чийто код е 48: `54 - 48 = 6`. Така първият ред показва символа 6 и кода 54, а вторият — `Digit: 6`. Същият подход работи за символите от `'0'` до `'9'`.

</details>

```
Изход:

Digit char: 6, Digit ASCII code: 54
Digit: 6
```
<br><br>
**Задача:** Да се напише програма, която чете число от 1 до 26 и изписва съответната буква от азбуката.

<details>
 <summary>Решение</summary>

```c++
#include <iostream>
using namespace std;

int main() {
  int num;
  cin >> num;
  char letterUpper = 'A' + num - 1;
  char letterLower = 'a' + num - 1;
  cout << letterUpper << " " << letterLower;
}
```
</details>

<details>
<summary>Обяснение на решението</summary>

Числото показва поредното място на буквата в латинската азбука. Понеже при вход 1 трябва да получим `A` и `a`, добавяме към тях `num - 1`. Например при вход **3** добавяме 2 позиции и получаваме **C c**. Приемаме ASCII и вход от 1 до 26; програмата не проверява дали въведеното число е в този диапазон.

</details>
