# Масиви

**Материал:** масиви: основни операции, обхождане на елементите, търсене.

**Правила:**
- използвайте обикновени (статични) масиви, например `int arr[1000];`.
- индексите започват от **0**. Когато задача пита за позиция, имайте предвид индекса;
- ако не е казано друго, на входа първо е броят на елементите `N`, а след него са самите `N` числа;
- силно препоръчително е да пишете функции, например `void readArray(int arr[], int n)` и `void printArray(int arr[], int n)`, и да ги преизползвате.

## Много лесни

### Задача 1: Обратен ред

Въведете `N` (1 ≤ N ≤ 100) и `N` цели числа. Изведете ги в обратен ред.

**Вход:**
```
5
1 2 3 4 5
```
**Изход:**
```
5 4 3 2 1
```

### Задача 2: Сбор и средно

Въведете `N` (1 ≤ N ≤ 100) и `N` цели числа. Изведете сбора и средното аритметично на елементите.

**Вход:**
```
4
3 8 -2 5
```
**Изход:**
```
Sum: 14
Average: 3.5
```

## Лесни

### Задача 3: Минимум и максимум

Въведете `N` (1 ≤ N ≤ 1000) и `N` цели числа. Изведете най-малкия и най-големия елемент и индекса, на който се срещат. Ако някой се среща няколко пъти, изведете **първия** индекс.

**Вход:**
```
6
4 -1 9 9 0 -1
```
**Изход:**
```
Min: -1 (index 1)
Max: 9 (index 2)
```

### Задача 4: Търсене на число

Въведете `N` (1 ≤ N ≤ 1000), `N` цели числа и накрая число `X`. Изведете:
- индекса на **първото** срещане на `X` в масива, или `-1`, ако го няма;
- колко пъти `X` се среща в масива.

**Вход:**
```
7
5 3 7 3 9 3 1
3
```
**Изход:**
```
First index: 1
Count: 3
```

**Вход:**
```
7
5 3 7 3 9 3 1
8
```
**Изход:**
```
First index: -1
Count: 0
```

> Подсказка: напишете функция `int linearSearch(int arr[], int n, int x)`, която връща индекса или `-1`.

## Средни

### Задача 5: По-големи от средното

Въведете `N` (1 ≤ N ≤ 1000) и `N` цели числа. Изведете всички елементи, които са **строго по-големи** от средното аритметично на масива, в реда, в който са въведени, и колко са те.

**Вход:**
```
6
2 8 4 10 1 5
```
**Изход:**
```
8 10
Count: 2
```

### Задача 6: Обръщане на място

Въведете `N` (1 ≤ N ≤ 1000) и `N` цели числа. **Обърнете масива на място**, т.е. без да използвате втори масив, като размените първия с последния елемент, втория с предпоследния и т.н. Изведете обърнатия масив.

След това изведете `Palindrome: Yes`, ако масивът се чете еднакво от двете страни, и `Palindrome: No` в противен случай.

**Вход:**
```
5
1 2 3 2 1
```
**Изход:**
```
1 2 3 2 1
Palindrome: Yes
```

**Вход:**
```
3
1 2 3
```
**Изход:**
```
3 2 1
Palindrome: No
```

### Задача 7: Ротация

Въведете `N` (1 ≤ N ≤ 1000), `N` цели числа и число `K` (0 ≤ K ≤ 1 000 000). Завъртете масива **наляво** с `K` позиции: при всяко завъртане първият елемент отива на последно място. Изведете резултата.

**Вход:**
```
5
1 2 3 4 5
2
```
**Изход:**
```
3 4 5 1 2
```

**Вход:**
```
5
1 2 3 4 5
7
```
**Изход:**
```
3 4 5 1 2
```

> Подсказка: какво се случва след `N` завъртания? Наистина ли трябва да въртите 1 000 000 пъти?

### Задача 8: Най-дълга растяща поредица

Въведете `N` (1 ≤ N ≤ 1000) и `N` цели числа. Намерете най-дългата поредица от **съседни** елементи, в която всеки следващ е строго по-голям от предишния. Изведете дължината ѝ и самите елементи. Ако има няколко с еднаква дължина, изведете първата.

**Вход:**
```
8
1 3 5 4 7 8 9 2
```
**Изход:**
```
Length: 4
4 7 8 9
```

**Вход:**
```
4
5 5 5 5
```
**Изход:**
```
Length: 1
5
```

## Трудни

### Задача 9: Двоично търсене

Въведете `N` (1 ≤ N ≤ 100 000) и `N` цели числа, **подредени в нарастващ ред**, без повторения. След това въведете `Q` (1 ≤ Q ≤ 100 000) и `Q` числа за търсене. За всяко от тях изведете индекса му в масива или `-1`, ако го няма.

Задължително използвайте **двоично търсене**: сравнете търсеното число със средния елемент и продължете търсенето само в лявата или само в дясната половина.

**Вход:**
```
6
1 3 5 7 9 11
4
7 4 1 11
```
**Изход:**
```
3
-1
0
5
```

> Защо е важно? При 100 000 елемента и 100 000 търсения линейното търсене прави до 10 000 000 000 сравнения, а двоичното прави около 1 700 000.

### Задача 10: Най-често срещаното число

Въведете `N` (1 ≤ N ≤ 100 000) и `N` цели числа от 1 до 100 000. Изведете:
- колко **различни** числа има в масива;
- кое число се среща най-често и колко пъти. Ако има няколко такива, изведете най-малкото от тях.

Решението трябва да е бързо: обхождането на целия масив за всяко число е твърде бавно.

**Вход:**
```
9
4 1 2 4 3 2 4 2 5
```
**Изход:**
```
Distinct: 5
Most frequent: 2 (3 times)
```

### Задача 11: Сливане на сортирани масиви

Въведете два масива, всеки **подреден в нарастващ ред**: първо `N` и `N` числа, след това `M` и `M` числа (1 ≤ N, M ≤ 1000). Слейте ги в трети масив, който също е подреден в нарастващ ред, и го изведете.

**Вход:**
```
4
1 4 6 9
5
2 3 6 10 12
```
**Изход:**
```
1 2 3 4 6 6 9 10 12
```

## LeetCode

### Задача 12: Max Consecutive Ones

**Линк към задачата:** https://leetcode.com/problems/max-consecutive-ones/

Даден е масив `nums`, съставен само от 0 и 1. Върнете най-голямия брой **поредни** единици в него.

**Пример:**
```
Вход: nums = [1,1,0,1,1,1]
Изход: 3
Обяснение: първите две единици са поредни, а последните три също. Най-много са 3.
```

**Ограничения:** 1 ≤ nums.length ≤ 10^5

### Задача 13: Two Sum

**Линк към задачата:** https://leetcode.com/problems/two-sum/

Дадени са масив `nums` и число `target`. Върнете индексите на **двата** елемента, чийто сбор е `target`. Гарантирано е, че има точно едно решение и един и същ елемент не може да се използва два пъти.

**Пример 1:**
```
Вход: nums = [2,7,11,15], target = 9
Изход: [0,1]
Обяснение: nums[0] + nums[1] = 2 + 7 = 9
```

**Пример 2:**
```
Вход: nums = [3,2,4], target = 6
Изход: [1,2]
```

**Ограничения:** 2 ≤ nums.length ≤ 10^4
