# C++ — масиви: основни операции, обхождане и търсене

*Кратка теория, примери и задачи*

## 1. Какво е масив?

Масивът съхранява няколко стойности от един и същ тип под едно име. Елементите се достъпват чрез индекс. В C++ индексите започват от 0.

```cpp
int a[5] = {12, 7, 4, 9, 15};
// индекс:  0  1  2  3   4
cout << a[0];  // 12
cout << a[3];  // 9
```

При `int a[5]` има 5 елемента: `a[0]` до `a[4]`. Достъпът до `a[5]` е извън границите на масива.

```cpp
const int N = 5;
int a[N];
for (int i = 0; i < N; i++) {
    cin >> a[i];
}
```

**Задача 1.** Създай масив от 6 цели числа, въведи елементите му и ги изведи в същия ред.

**Задача 2.** Въведи `n` (1 ≤ n ≤ 100), после `n` числа в `int a[100]`. Изведи първия, последния и средния елемент, ако `n` е нечетно.

## 2. Обхождане на елементите

Обхождане означава да посетим елементите един по един, най-често с `for` цикъл. Индексът `i` се движи от 0 до `n - 1`.

```cpp
for (int i = 0; i < n; i++) {
    cout << a[i] << " ";
}
```

Същият шаблон се използва за сума, броене, минимум/максимум и други операции.

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}
cout << sum;
```

**Задача 3.** Намери сумата и средноаритметичната стойност на `n` числа. Използвай `int` за сумата и `double` за средното.

**Задача 4.** Намери най-малкия и най-големия елемент. Започни с `minValue = a[0]` и `maxValue = a[0]`, след което обхождай от индекс 1.

## 3. Броене по условие

Започни брояча от 0 и го увеличавай, когато елементът отговаря на условието.

```cpp
int evenCount = 0;
for (int i = 0; i < n; i++) {
    if (a[i] % 2 == 0) {
        evenCount++;
    }
}
```

**Задача 5.** Намери колко елемента са положителни, отрицателни и равни на 0.

**Задача 6.** Намери броя на елементите, които са по-големи от средноаритметичната стойност на масива.

## 4. Търсене на елемент

Линейното търсене проверява елементите последователно. Работи и когато масивът не е сортиран.

```cpp
int x;
cin >> x;
int position = -1;
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        position = i;
        break;
    }
}
if (position == -1) {
    cout << "Nqma takuv element";
} else {
    cout << "Indeks: " << position;
}
```

`position = -1` означава, че елементът не е намерен. `break` прекратява цикъла при първото съвпадение. Индексите започват от 0.

**Задача 7.** Въведи `x` и изведи индекса на първото му срещане. Ако липсва, изведи -1.

**Задача 8.** Намери всички индекси, на които се среща `x`, и преброй срещанията му. Не прекратявай цикъла при първото съвпадение.

## 5. Промяна на елементи и обръщане

Елемент се променя чрез индекса си. За обръщане разменяме първия с последния, втория с предпоследния и т.н.

```cpp
for (int i = 0; i < n / 2; i++) {
    int temp = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = temp;
}
```

**Задача 9.** Увеличи с 1 всеки четен елемент и изведи получения масив.

**Задача 10.** Обърни масива на място, без втори масив, и изведи резултата.

## 6. Намиране на позиция

Когато търсиш позицията на минимум или максимум, пази индекса, а не само стойността.

```cpp
int minIndex = 0;
for (int i = 1; i < n; i++) {
    if (a[i] < a[minIndex]) {
        minIndex = i;
    }
}
cout << minIndex;
```

**Задача 11.** Намери индекса на първия максимален елемент. Ако максимумът се повтаря, запази най-малкия индекс.

**Задача 12.** Намери втория по големина различен елемент. Ако няма такъв, изведи съобщение.

## 7. По-сложни задачи

**Задача 13.** Премести всички нули в края, като запазиш относителния ред на останалите елементи. Използвай само един масив.

**Задача 14.** Провери дали масивът е палиндром — първият елемент трябва да е равен на последния, вторият на предпоследния и т.н.

**Задача 15.** Намери дължината на най-дългата непрекъсната строго нарастваща поредица от елементи.

**Задача 16.** За всяка различна стойност изведи колко пъти се среща, без да извеждаш една и съща стойност повече от веднъж. Не използвай втори масив.

## Чести грешки

- Последният валиден индекс е `n - 1`, а не `n`.
- Използвай `i < n`, а не `i <= n`.
- Инициализирай минимум и максимум с `a[0]`, а не с 0.
- При търсене на всички срещания не използвай `break`.
- Не използвай `a[0]`, ако `n` е 0. Приеми `n ≥ 1`, освен ако условието не казва друго.

## Обобщение

- Декларация: `int a[100];`
- Индексите са от 0 до `n - 1`.
- Обхождане: `for (int i = 0; i < n; i++)`.
- Линейно търсене: сравнявай `a[i]` с търсената стойност.
- Пази индекс, ако ти трябва позицията.
- Не използвай индекс извън границите на масива.
