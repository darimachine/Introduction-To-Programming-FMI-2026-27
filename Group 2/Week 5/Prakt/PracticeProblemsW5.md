##### Задача 4
Напишете функция, която приема масив от числа и неговия размер.
Елементите на масива представляват число,
като последния елемент е цифрата на единиците,
предпоследния - на десетиците, предпредпоследния - стотиците и така нататък.
Трябва да симулирате прибавянето на единица към това число 
и да промените елементите в него, така че те да репрезентират 
новополученото число. 
Накрая функцията трябва да принтира този масив(без водещата нула, 
ако все още има такава).

*Забележка*: Можем да приемем, че масиват има предварително заделен 
празен елемент в началото(водеща нула), в случай че новополученото число
трябва да има една цифра повече, например 999 -> 1000.

Вход:
```C++
int size = 6;
int numbers[] = {0, 1, 2, 3, 4, 5};

solution_4(numbers, size);
```
Изход:
```C++
1 2 3 4 5 6
```
<br>

Вход:
```C++
int size = 4;
int numbers[] = {0, 9, 9, 9};

solution_4(numbers, size);
```
Изход:
```C++
1 0 0 0
```
