# C++ — двумерни масиви и функции

*Кратка теория, кодови примери и различни задачи*

## 1. Двумерен масив

Двумерният масив е таблица от редове и колони. Елементът се достъпва с два индекса: `a[ред][колона]`. Индексите започват от 0.

```cpp
int a[3][4] = {{2, 4, 6, 8},
                {1, 3, 5, 7},
                {9, 0, 2, 4}};
cout << a[1][2]; // 5
```

Тук има 3 реда и 4 колони. `a[1][2]` е вторият ред, третата колона.

**Задача 1.** Декларирай `int a[2][3]`, въведи шест числа и изведи матрицата като 2 реда по 3 елемента.

## 2. Обхождане

Външният цикъл обхожда редовете, а вътрешният — колоните.

```cpp
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++)
        cout << a[i][j] << " ";
    cout << endl;
}
```

**Задача 2.** Въведи матрица 3×3 и намери сумата на всички елементи.

**Задача 3.** Намери минимума в матрица `rows×cols`. Приеми, че размерите са положителни.

## 3. Редове, колони и диагонали

За сума по ред фиксираме `i`, за сума по колона фиксираме `j`. В квадратна матрица главният диагонал е `a[i][i]`, вторичният — `a[i][n-1-i]`.

```cpp
int sumMain = 0;
for (int i = 0; i < n; i++)
    sumMain += a[i][i];
```

**Задача 4.** Намери сумите на главния и вторичния диагонал на квадратна матрица.

**Задача 5.** Намери индекса на реда с най-голяма сума. При равенство избери най-малкия индекс.

## 4. Функции с двумерен масив

При статичен двумерен масив функцията трябва да знае броя колони. Той се задава в параметъра, а броят редове може да се подаде отделно.

```cpp
const int COLS = 3;
void printMatrix(int a[][COLS], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < COLS; j++)
            cout << a[i][j] << " ";
        cout << endl;
    }
}
```

Пример за извикване: `int m[2][3]; printMatrix(m, 2);` Размерът на колоните в аргумента трябва да съвпада с `COLS`.

**Задача 6.** Напиши `void inputMatrix(int a[][3], int rows)`, която въвежда матрица с 3 колони.

**Задача 7.** Напиши `int sumMatrix(int a[][4], int rows)`, която връща сумата на всички елементи в матрица с 4 колони.

## 5. Референтни параметри за допълнителни резултати

Функцията може да върне един резултат чрез `return`, а други чрез параметри по референция (`int&`).

```cpp
void findMinMax(int a[][3], int rows, int& mn, int& mx) {
    mn = a[0][0]; mx = a[0][0];
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < 3; j++) {
            if (a[i][j] < mn) mn = a[i][j];
            if (a[i][j] > mx) mx = a[i][j];
        }
}
```

**Задача 8.** Напиши функция `bool contains(int a[][4], int rows, int x)`, която връща `true`, ако `x` се среща в матрицата.

**Задача 9.** Напиши `void diagonalSums(int a[][3], int& mainSum, int& secondarySum)`, която намира сумите на двата диагонала на матрица 3×3.

## 6. Пълен пример

```cpp
#include <iostream>
using namespace std;
const int COLS = 3;
int sumMatrix(int a[][COLS], int rows) {
    int sum = 0;
    for (int i = 0; i < rows; i++)
        for (int j = 0; j < COLS; j++) sum += a[i][j];
    return sum;
}
void printMatrix(int a[][COLS], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < COLS; j++) cout << a[i][j] << " ";
        cout << endl;
    }
}
int main() {
    int a[2][COLS] = {{1, 2, 3}, {4, 5, 6}};
    printMatrix(a, 2);
    cout << sumMatrix(a, 2);
}
```

## Чести грешки

- `a[i][j]` означава ред `i` и колона `j`.
- Валидните индекси за `rows` реда са 0…`rows-1`.
- Не забравяй вътрешния цикъл, когато обработваш всички колони.
- При параметър `int a[][COLS]` броят колони трябва да е известен и съвпадащ.
- Диагоналите са дефинирани за квадратна матрица.

## Обобщение

- Достъп до елемент: `a[i][j]`.
- Обхождане: два вложени `for` цикъла.
- Главен диагонал: `a[i][i]`.
- Вторичен диагонал: `a[i][n-1-i]`.
- Функционален параметър: `int a[][COLS]`, с фиксиран брой колони.
- Допълнителни резултати могат да се подават чрез референции.
