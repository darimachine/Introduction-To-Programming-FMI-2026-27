# C++ — теория и задачи

Оператори • Цикли • switch • break • continue • L-value и R-value

## 1. Оператори

Аритметични оператори: `+`, `-`, `*`, `/`, `%`.

Оператори за сравнение: `==`, `!=`, `<`, `>`, `<=`, `>=`.

Оператори за присвояване: `=`, `+=`, `-=`, `*=`, `/=`.

> Операторът `=` присвоява стойност, а `==` сравнява.

Логически оператори: `&&` („И“), `||` („ИЛИ“), `!` („НЕ“).

Увеличаване и намаляване: `++`, `--`.

Условен: `?` &nbsp;&nbsp;&nbsp;&nbsp; `x > 0 ? x : -x`

```cpp
int x = 7;
cout << x / 2 << '\n';              // 3
cout << x % 2 << '\n';              // 1
cout << (x > 5 && x < 10) << '\n';  // 1 (true)
```

### ++i и i++

При `i++` старата стойност се използва в израза, след което `i` се увеличава. При `++i` първо се увеличава `i`, а после се използва новата стойност.

```cpp
int i = 5;
int a = i++;  // a = 5, i = 6

int j = 5;
int b = ++j;  // b = 6, j = 6
```

### Задача

**Условия и ++.** Въведи N и изведи числата от 1 до N, които се делят на 3, но не се делят на 2.

Предвиди резултата от кода:

```cpp
int x=3;
int a=x++;
int b=++x;
cout << x << " " << a << " " << b;
```

## 2. Цикъл for

Използва се, когато знаем броя на повторенията. Състои се от начална стойност, условие и промяна след всяка итерация.

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << ' ';
}
// 1 2 3 4 5
```

## 3. Цикъл while

Използва се, когато броят повторения зависи от условие. Например при обработка на цифри `n % 10` взема последната цифра, а `n /= 10` я премахва.

```cpp
int n = 1234;
while (n > 0) {
    cout << n % 10 << ' ';
    n /= 10;
}
// 4 3 2 1
```

## 4. Цикъл do-while

Тялото на `do-while` се изпълнява поне веднъж, защото условието се проверява след него.

```cpp
int x;
do {
    cin >> x;
} while (x < 1 || x > 10);
```

## 5. Вложени цикли

Вложен цикъл се намира в тялото на друг цикъл. Външният често управлява редовете, а вътрешният — елементите във всеки ред.

```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 4; j++) {
        cout << '*';
    }
    cout << '\n';
}
```

## 6. break и continue

### break

`break` прекратява най-близкия цикъл или излиза от текущия `switch`.

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    cout << i << ' ';
}
// 1 2 3 4
```

### continue

`continue` пропуска остатъка от текущата итерация. При `for` след него се изпълнява промяната на цикъла; при `while` се проверява условието отново.

```cpp
for (int i = 1; i <= 6; i++) {
    if (i % 2 == 0) continue;
    cout << i << ' ';
}
// 1 3 5
```

## 7. switch

`switch` избира клон според стойността на израз. `case` задава конкретна стойност, `default` обработва останалите случаи. `break` предотвратява преминаването към следващ `case`.

```cpp
int choice = 2;
switch (choice) {
    case 1: cout << "One"; break;
    case 2: cout << "Two"; break;
    case 3: cout << "Three"; break;
    default: cout << "Invalid";
}
```

## 8. L-value и R-value

Двете страни на `=` не са еднакви. Отляво трябва да има място, в което стойността да се запише. Отдясно стои самата стойност.

**L-value** е израз, който сочи към такова място — обикновено променлива. Името идва от *left*: изменяем l-value може да стои отляво на `=`.

**R-value** е стойност, която се изчислява, но няма собствено място за запис. Името идва от *right*. Число, сбор и друг временен резултат са r-value. В тях не може да се присвоява.

L-value може да стои и отдясно: тогава се чете стойността му. R-value не може да стои отляво.

```cpp
int x = 10;
x = 20;            // x е място за запис: l-value
int y = x + 5;     // x + 5 е сметка без собствено място: r-value (заделя се някаква временна памет преди присвояването)
// (x + 5) = 20;   // грешка: няма къде да се запише 20
// 10 = x;         // грешка: числото също е r-value
```

### Префикс и постфикс

`++x` първо увеличава `x` и като резултат дава самата променлива. Затова `++x` е l-value и в нея може да се присвои.

`x++` също увеличава `x`, но връща старата стойност като временно число. Това е r-value и в него не може да се присвои.

```cpp
int x = 5;
++x = 9;   // валидно: ++x е самата променлива x
// x++ = 9; // невалидно: x++ е временната стара стойност
```

### Задачи

**16. Категории на изразите.** Определи кои изрази са l-value и кои са r-value: `x`, `42`, `x+1`, `++x`, `x++`, `(x=10)`.

**17. Валиден ли е кодът?** За всеки ред обясни дали се компилира: `int x=5; const int c=10; x=7; (x+1)=8; ++x=9; x++=9; c=20;`
