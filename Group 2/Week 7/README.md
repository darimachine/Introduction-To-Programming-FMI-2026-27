# Задачи по C++: Побитови операции

**Материал:** побитовите оператори `&`, `|`, `^`, `~`, `<<`, `>>`.

**Правила:**
- без `vector`, `string` и `bitset`. Всичко се решава с побитови оператори;
- битовете се номерират отдясно наляво, като започват от **0**. Например в `10 = 1010` бит 0 е `0`, бит 1 е `1`, бит 2 е `0`, бит 3 е `1`;
- ако не е казано друго, числата на входа са цели и неотрицателни и се побират в `int`.

**Кратка справка:**

| Оператор | Име | Пример | Резултат |
|----------|-----|--------|----------|
| `a & b` | И (AND) | `1100 & 1010` | `1000` |
| `a \| b` | ИЛИ (OR) | `1100 \| 1010` | `1110` |
| `a ^ b` | Изключващо ИЛИ (XOR) | `1100 ^ 1010` | `0110` |
| `~a` | Отрицание (NOT) | `~1100` | `...0011` |
| `a << k` | Изместване наляво | `0011 << 2` | `1100` |
| `a >> k` | Изместване надясно | `1100 >> 2` | `0011` |

| № | Задача | Трудност |

## Много лесни

### Задача 1: Четно или нечетно

Въведете цяло число `N`. Изведете `Even`, ако е четно, и `Odd`, ако е нечетно. **Не използвайте** `%`, а побитов оператор.

**Вход:**
```
7
```
**Изход:**
```
Odd
```

**Вход:**
```
10
```
**Изход:**
```
Even
```

> Подсказка: кой бит определя дали числото е четно?

### Задача 2: Умножение и деление по степен на 2

Въведете числата `N` и `K` (0 ≤ K ≤ 20). Изведете `N`, умножено по 2^K, и `N`, целочислено разделено на 2^K. **Не използвайте** `*`, `/` и `pow`.

**Вход:**
```
100 2
```
**Изход:**
```
400
25
```

> Подсказка: какво става с числото `0011`, когато всички битове се изместят с една позиция наляво?

## Лесни

### Задача 3: Работа с един бит

Въведете числата `N` и `K` (0 ≤ K ≤ 30). Изведете:
1. стойността на бит `K` в `N` (`0` или `1`);
2. числото, което се получава, ако **вдигнете** бит `K` (направите го `1`);
3. числото, което се получава, ако **свалите** бит `K` (направите го `0`);
4. числото, което се получава, ако **обърнете** бит `K`.

**Вход:**
```
10 2
```
**Изход:**
```
Bit: 0
Set: 14
Clear: 10
Toggle: 14
```

Обяснение: `10 = 1010`. Бит 2 е `0`. При вдигане става `1110 = 14`, при сваляне остава `1010 = 10`, а при обръщане става `1110 = 14`.

**Вход:**
```
10 1
```
**Изход:**
```
Bit: 1
Set: 10
Clear: 8
Toggle: 8
```

> Подсказка: числото `1 << K` има само един вдигнат бит: точно бит `K`. Наричаме го **маска**.

### Задача 4: Двоичен запис

Въведете цяло неотрицателно число `N`. Изведете двоичния му запис без водещи нули. Използвайте само `>>` и `&`, без `%` и `/`.

**Вход:**
```
10
```
**Изход:**
```
1010
```

**Вход:**
```
255
```
**Изход:**
```
11111111
```

**Вход:**
```
0
```
**Изход:**
```
0
```

> Подсказка: първо намерете най-старшия вдигнат бит, а после изведете битовете от него надолу до бит 0.

## Средни

### Задача 5: Брой единици и степен на 2

Въведете цяло неотрицателно число `N`. Изведете:
- колко бита в `N` са `1`;
- дали `N` е степен на 2: `Power of two: Yes` или `Power of two: No`. Числото 0 не е степен на 2.

Проверката за степен на 2 трябва да е **с един израз, без цикъл**.

**Вход:**
```
12
```
**Изход:**
```
Ones: 2
Power of two: No
```

**Вход:**
```
64
```
**Изход:**
```
Ones: 1
Power of two: Yes
```

> Подсказка: запишете в двоична система `8` и `7`, после `12` и `11`. Какво е `N & (N - 1)`?

### Задача 6: Размяна без трета променлива

Въведете две цели числа `a` и `b`. Разменете стойностите им, **без да използвате трета променлива**, като използвате само `^`. Изведете ги след размяната.

**Вход:**
```
5 9
```
**Изход:**
```
a = 9, b = 5
```

След това отговорете в коментар в кода: какво ще стане, ако приложите същия трик за размяна на един елемент сам със себе си, т.е. когато `a` и `b` са **една и съща променлива**?

> Подсказка: какво е `x ^ x`? А `x ^ 0`?

### Задача 7: Числото без двойка

Въведете `N` (1 ≤ N ≤ 1 000 000, нечетно) и `N` цели числа. Всяко число се среща точно два пъти, освен едно, което се среща веднъж. Изведете него.

Решението трябва да **не използва масив**: четете числата едно по едно.

**Вход:**
```
7
4 1 2 1 2 4 3
```
**Изход:**
```
3
```

> Подсказка: какво е `a ^ b ^ a`?

### Задача 8: Множества с битове

Едно множество от числа между 0 и 31 може да се пази в **едно** `int` число: бит `i` е `1`, ако числото `i` е в множеството. Например множеството {1, 3} се пази като `1010 = 10`.

Въведете две множества: първо броя на елементите и елементите на `A`, а после броя на елементите и елементите на `B`. Всички елементи са от 0 до 30 и не се повтарят. Постройте маските на двете множества и изведете:
- маските на `A` и `B` като числа;
- **обединението** `A ∪ B`: елементите, които са в `A` или в `B`;
- **сечението** `A ∩ B`: елементите, които са и в `A`, и в `B`;
- **разликата** `A \ B`: елементите, които са в `A`, но не са в `B`;
- **симетричната разлика**: елементите, които са само в едното от двете множества.

Изведете множествата като списък от елементи в нарастващ ред. Празното множество изведете като `{}`.

**Вход:**
```
4
1 3 5 7
3
3 4 5
```
**Изход:**
```
Mask A: 170
Mask B: 56
Union: 1 3 4 5 7
Intersection: 3 5
Difference: 1 7
Symmetric difference: 1 4 7
```

> Подсказка: всяка от четирите операции е **един** побитов израз. Напишете функция, която извежда елементите на множество по дадена маска, и я извикайте 4 пъти.

## Трудни

### Задача 9: Двете числа без двойка

Въведете `N` (2 ≤ N ≤ 1 000 000, четно) и `N` цели неотрицателни числа. Всяко число се среща точно два пъти, освен **две различни** числа, които се срещат по веднъж. Изведете ги в нарастващ ред.

Решението трябва да е бързо и да **не използва масив** за броене. Числата може да прочетете в масив, но трябва да ги обходите най-много два пъти.

**Вход:**
```
6
2 4 3 2 7 4
```
**Изход:**
```
3 7
```

> Подсказка: XOR на всички числа дава `x ^ y`, където `x` и `y` са търсените. Щом `x ≠ y`, в `x ^ y` има поне един вдигнат бит. Какво означава той за `x` и `y`? Как да разделите всички числа на две групи по него?

### Задача 10: Подмножества със зададен сбор

Въведете `N` (1 ≤ N ≤ 20), `N` цели положителни числа и число `S`. Изведете всички подмножества на числата, чийто сбор е точно `S`, и накрая колко са.

Всяко подмножество съответства на маска от `0` до `2^N - 1`: ако бит `i` на маската е `1`, `i`-тото число е в подмножеството. Обходете маските в нарастващ ред. За всяко намерено подмножество изведете числата му в реда, в който са въведени.

**Вход:**
```
4
1 2 3 4
5
```
**Изход:**
```
2 3
1 4
Count: 2
```

Обяснение: подмножеството {2, 3} е маската `0110 = 6`, а {1, 4} е `1001 = 9`. Маска 6 е преди 9, затова {2, 3} се извежда първо.

**Вход:**
```
5
3 1 4 2 5
6
```
**Изход:**
```
3 1 2
4 2
1 5
Count: 3
```

> Подсказка: колко маски има? Как се изчислява `2^N` с побитов оператор?
