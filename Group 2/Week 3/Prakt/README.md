# Задачи: Функции

**Материал:** типове данни, `cin`/`cout`, `if`/`switch`, `for`/`while` и **функции**.

**Ограничения:**
- без масиви, `vector` и низове (`string`). Използвайте само обикновени типове: `int`, `long long`, `double`, `char`, `bool`;
- текст в кавички се извежда направо с `cout`, например `cout << "Да";`.

**Главното правило:** задачата се решава **изцяло във функцията**. `main()` само:
1. прочита входа с `cin`;
2. извиква функцията;
3. извежда резултата с `cout`.

Във функцията не се използват `cin` и `cout`. Тя получава данните като параметри и връща резултата с `return`.

```cpp
#include <iostream>
using namespace std;

// Функцията решава задачата
int sum(int a, int b) {
    return a + b;
}

int main() {
    int a, b;
    cin >> a >> b;            // 1. входът
    cout << sum(a, b);        // 2. извикване и 3. изход
    return 0;
}
```

## LeetCode: Рекурсия

**Рекурсия** е, когато функция извиква сама себе си. Всяка рекурсивна функция има нужда от:
1. **дъно (базов случай):** кога спираме и връщаме отговора директно;
2. **рекурсивна стъпка:** как свеждаме задачата до по-малка задача от същия вид.

```cpp
// Пример: n! = n * (n - 1)!
long long factorial(int n) {
    if (n <= 1) {                     // дъно
        return 1;
    }
    return n * factorial(n - 1);      // рекурсивна стъпка
}
```

В LeetCode функцията е вътре в `class Solution { public: ... };`. Не се притеснявайте от това: пишете само тялото на функцията, както досега. Двете задачи решете с **рекурсия**, без цикли.

### Задача 9: Fibonacci Number

**Линк към задачата:** https://leetcode.com/problems/fibonacci-number/

Числата на Фибоначи се определят така:
- `F(0) = 0`, `F(1) = 1`;
- `F(n) = F(n - 1) + F(n - 2)` за `n > 1`.

Дадено е `n`. Върнете `F(n)`.

```cpp
int fib(int n)
```

**Пример:**
```
Вход: n = 4
Изход: 3
Обяснение: F(4) = F(3) + F(2) = 2 + 1 = 3
```

**Ограничения:** 0 ≤ n ≤ 30

### Задача 10: Power of Two

**Линк към задачата:** https://leetcode.com/problems/power-of-two/

Дадено е цяло число `n`. Върнете `true`, ако `n` е степен на двойката (1, 2, 4, 8, 16, ...), и `false` в противен случай.

```cpp
bool isPowerOfTwo(int n)
```

**Пример 1:**
```
Вход: n = 16
Изход: true
```

**Пример 2:**
```
Вход: n = 6
Изход: false
```

**Пример 3:**
```
Вход: n = 1
Изход: true
Обяснение: 2 на степен 0 е 1.
```

**Ограничения:** -2^31 ≤ n ≤ 2^31 - 1
