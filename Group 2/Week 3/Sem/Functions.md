# C++ — функции, подаване по стойност и по референция

## 1. Какво е функция?

Функцията е именуван блок код, който изпълнява конкретна задача. Тя позволява да разделим програмата на части и да използваме код многократно.

```cpp
int sum(int a, int b) {
    return a + b;
}

int main() {
    int result = sum(3, 5);  // result е 8
}
```

В `int sum(int a, int b)`, `int` е типът на резултата, `sum` е името, а `a` и `b` са параметри. `return` връща резултата и приключва функцията. Ако не се връща стойност, се използва `void`.

Пример:

```cpp
void printLine() {
    cout << "----------" << endl;
}
```

## 2. Декларация, дефиниция и извикване

Дефиницията съдържа кода на функцията. Ако тя е написана след `main()`, преди `main()` постави декларация (прототип), за да знае компилаторът как се извиква.

```cpp
int square(int n);  // прототип

int main() {
    cout << square(6);
}

int square(int n) {
    return n * n;
}
```

## 3. Подаване по стойност

При подаване по стойност функцията получава копие на аргумента. Промяната на параметъра не променя оригиналната променлива.

```cpp
void change(int x) {
    x = 100;
}
int main() {
    int n = 5;
    change(n);
    cout << n;  // 5
}
```

Параметърът `x` е отделна променлива, която първоначално получава стойността на `n`.

```cpp

int main() {

    f(a);
    cout << a;
}
```

## 4. Подаване по референция

При подаване по референция параметърът е друго име за оригиналната променлива. В C++ пишем `&` след типа на параметъра. Промените във функцията се виждат извън нея.

```cpp
void change(int& x) {
    x = 100;
}
int main() {
    int n = 5;
    change(n);
    cout << n;  // 100
}
```

В `int& x` амперсандът означава, че `x` е референция към подадената променлива.

## 5. Стойност или референция?

| Запис | Какво получава функцията | Променя оригинала? |
|---|---|---|
| `int x` | Копие на стойността | Не |
| `int& x` | Достъп до оригиналната променлива | Да, ако я променя |
| `const int& x` | Референция, през която не може да се променя | Не през този параметър |

Използвай стойност, когато е достатъчно функцията да работи с копие. Използвай референция, когато трябва да промени аргумента или да върне няколко резултата чрез параметрите.

## 6. Повече от един резултат чрез референции

Функцията може да върне един резултат с `return` и да запише допълнителни резултати в референтни параметри.

```cpp
void quotientAndRemainder(int a, int b, int& q, int& r) {
    q = a / b;
    r = a % b;
}
int main() {
    int q, r;
    quotientAndRemainder(17, 5, q, r);
    // q е 3, r е 2
}
```

Предполага се, че `b` не е 0.

## 7. const референция

`const int&` позволява достъп до оригиналната променлива без копиране, но забранява промяната ѝ през този параметър.

```cpp
void printNumber(const int& x) {
    cout << x;
    // x = 4;  // грешка: x е const
}
```

**Задача 11.** Определи изхода и крайната стойност на `a`.

## Обобщение

- Функцията има име, параметри и тип на резултата.
- `return` връща резултат и приключва функцията.
- При подаване по стойност параметърът е копие.
- При подаване по референция (`тип&`) параметърът обозначава оригиналната променлива.
- `const тип&` позволява достъп без копиране, но забранява промяна през този параметър.
- Референциите са полезни за промяна на аргументи и за връщане на няколко резултата.
