# C++

## Указатели. Памет. Адресна аритметика. Бройни системи и побитови операции


## 1. Памет и адреси

Всяка променлива по време на изпълнение заема област от оперативната памет (RAM). Адресът е число, което обозначава местоположението на тази област; често се показва в шестнадесетичен формат. Адресите в примерите са условни.

```cpp
int x = 25;
cout << &x;       // адрес на x
cout << sizeof(x); // размер в байтове
```

`sizeof(type)` показва размера на типа на конкретната платформа. Не приемайте, че `int` винаги е с един и същ размер на всички системи.

## 2. Указатели

Указател (pointer) е променлива, която пази адрес на обект. Типът му определя към какъв тип обект сочи.

```cpp
int x = 7;
int* p = &x;  // p пази адреса на x
cout << p;    // адрес
cout << *p;   // стойността на x: 7
*p = 12;      // x вече е 12
```

`&x` — оператор за вземане на адрес. `*p` — разименуване: достъп до обекта през указателя. `nullptr` означава, че указателят не сочи към валиден обект.

```cpp
int* p = nullptr;
if (p != nullptr) cout << *p;
```

Не разименувайте неинициализиран указател, `nullptr` или адрес извън валиден обект. `*` в `int* p` е част от декларацията, а `*p` в израз е разименуване.

## 3. Указатели и масиви

Името на масив в повечето изрази се преобразува до указател към първия елемент. Масивът не е самият указател: той има фиксиран размер, а указателят е променлива.

```cpp
int a[5] = {10,20,30,40,50};
int* p = a;        // същото като &a[0]
cout << *p;        // 10
cout << *(p+2);    // 30
cout << a[2];      // 30
```

За `n` елемента валидни индекси са `0..n-1`. Може да се получи указател към позицията непосредствено след последния елемент, но тя не се разименува.

## 4. Адресна аритметика

`p+k` придвижва указателя с `k` елемента от типа, а не с `k` байта. За `int* p`, `p+1` сочи към следващия `int`; компилаторът отчита `sizeof(int)`.

```cpp
int a[4] = {3,6,9,12};
int* p = a;
cout << *(p+1); // 6
cout << *(p+3); // 12
p++;            // придвижване към следващ елемент
```

`p--` придвижва назад в рамките на масива. `p2-p1` дава разстояние в елементи, когато двата указателя сочат в един и същ масив. Не правете аритметика с несвързани обекти.

### Обхождане с указател

```cpp
int a[5] = {4,1,8,2,7};
int* p = a;
for (int i=0; i<5; i++)
    cout << *(p+i) << " ";
```

Достъпът `a[i]` често е по-четим; указателите са полезни за разбиране на адресите и за параметри на функции.

## 5. Масиви и указатели във функции

Функция, която приема указател към първи елемент, обикновено трябва да получи и размера `n`, защото не може автоматично да разбере дължината на масива.

```cpp
int sumPtr(const int* p, int n) {
    int s=0;
    for (int i=0; i<n; i++) s += *(p+i);
    return s;
}
// int a[4]={2,4,6,8}; sumPtr(a,4) -> 20
```

`const` се чете според това до кое стои.

`const int* p` (същото като `int const* p`) пази обикновен указател, но забранява промяна на стойността през него. Самият `p` може да се пренасочи към друг адрес. Така функцията чете елементите, без да ги променя.

`int* const p` е обратният случай: адресът в `p` е фиксиран и не може да сочи към друга променлива, но стойността на този адрес може да се променя.

```cpp
int x = 7, y = 9;
const int* a = &x;
a = &y;     // валидно: a сочи към друго място
// *a = 3;  // грешка: стойността през a е const

int* const b = &x;
*b = 3;     // валидно: x става 3
// b = &y;  // грешка: адресът в b е const
```

Ако и двете са заключени, записът е `const int* const p`: нито адресът, нито стойността през указателя могат да се променят.

Може да се използва и референция за връщане на допълнителен резултат.

```cpp
void minMax(const int* a, int n, int& mn, int& mx) {
    mn=mx=a[0];
    for(int i=1;i<n;i++){
        if(a[i]<mn) mn=a[i];
        if(a[i]>mx) mx=a[i];
    }
}
```

Предусловие: `n>0`. `mn` и `mx` са референции, през които функцията връща два резултата.

## 6. Двумерни масиви и адреси

Двумерният масив е масив от масиви; елементите са подредени последователно по редове. При статичен масив параметърът на функция трябва да посочва броя колони.

```cpp
const int COLS=3;
void printMatrix(const int a[][COLS], int rows) {
  for(int i=0;i<rows;i++) {
    for(int j=0;j<COLS;j++) cout<<a[i][j]<<" ";
    cout<<endl;
  }
}
```

Концептуално ред `i` започва след `i` реда, всеки с `COLS` елемента. Не е нужно да заменяте всеки индекс с указател; важно е да разбирате свързаността.

## 7. Бройни системи

Десетична основа 10, двоична основа 2, осмична основа 8, шестнадесетична основа 16. В шестнадесетичната система A–F означават 10–15.

1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 11₁₀. 2F₁₆ = 2·16 + 15 = 47₁₀.

```cpp
int x=47;
cout << dec << x; // 47
cout << oct << x; // 57
cout << hex << x; // 2f
```

C++ стандартните потоци не предоставят обикновен manipulator `bin` за двоично извеждане. За двоичен формат може да се реализира функция с проверка на битовете.

## 8. Побитови операции

| Оператор | Название | Смисъл |
|---|---|---|
| `&` | AND | бит 1 само ако и двата са 1 |
| `\|` | OR | бит 1 ако поне един е 1 |
| `^` | XOR | бит 1 ако са различни |
| `~` | NOT | обръща битовете |
| `<<` | изместване наляво | премества битовете наляво |
| `>>` | изместване надясно | премества битовете надясно |

Пример: `a=10` (1010₂), `b=6` (0110₂). `a&b=2` (0010₂), `a|b=14` (1110₂), `a^b=12` (1100₂), `a<<1=20` (10100₂).

```cpp
if ((x & (1 << k)) != 0) // проверка на k-тия бит
x |= (1 << k);             // включване
x &= ~(1 << k);            // изключване
x ^= (1 << k);             // обръщане
```

В учебните примери `x` е неотрицателно и `k` е валидна позиция за типа. `&` като адресен оператор (например `&x`) не бива да се бърка с побитовото AND (`x&y`). `&&` и `\|\|` са логически оператори.

## 9. Безопасност и типични грешки

- Инициализирайте указателите; не разименувайте `nullptr`.
- Не излизайте извън границите на масив.
- Не връщайте адрес на локална променлива от функция.
- Не приемайте фиксиран `sizeof(int)` или конкретен адрес за всички системи.
- `p+1` означава следващ елемент от типа, не следващ байт.
- Битовите операции са върху цели числа; `&&` и `\|\|` са логически.

## 10. Пример: броене на четни числа през указател

```cpp
int countEven(const int* p, int n) {
  int count=0;
  for(int i=0;i<n;i++)
    if(*(p+i)%2==0) count++;
  return count;
}
// {3,8,2,7,10,5}, n=6 -> 3
```

Функцията приема адреса на първия елемент и броя на елементите; `*(p+i)` осигурява достъп до всеки елемент.

## 13. Мини речник

- **Памет** — област за съхраняване на данни по време на изпълнение.
- **Адрес** — местоположение на обект в паметта.
- **Указател** — променлива, която съдържа адрес.
- **Разименуване** — достъп до обект чрез указател.
- **Адресна аритметика** — придвижване между елементи.
- **Битова маска** — число за проверка/промяна на конкретни битове.
- **Неопределено поведение** — ситуация, при която стандартът не гарантира резултат.
